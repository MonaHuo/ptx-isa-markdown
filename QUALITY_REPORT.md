Runtime/Driver API source pages are loaded from the current `cuda_runtime_api/` and `cuda_driver_api/` paths. Every downloaded or cached page must identify the expected API and version in its title. The legacy top-level module URLs were observed to serve older 13.3.1 documentation and are not used.

Code verification compares source text with fenced code or HTML preformatted cells. Indentation and blank lines are retained; trailing horizontal whitespace is normalized. Merged cells, nested lists, literal pipe operators, and tables containing code use HTML to avoid losing their structure. Image counts reflect the source document; diagrams are referenced rather than downloaded.

The previous conversion duplicated nested content and omitted some parent sections. The new conversion gives each section one owner, retains deeper sections inside their parent file, generates a working index, and includes notices in their own chapter. Historical 9.1 and earlier release notes remain as version history.

The converter removes a summary only if its detailed definitions exist on the same page. Parameters, return values, semantic notes, and “See also” names remain. API symbol URLs are reduced to readable names; the original page URL is retained for authoritative navigation.

## Automated checks

Nine regression tests cover nested section ownership, local cross-references, complex tables and code, version mismatch rejection, stale-file cleanup, repeatable generation, union discovery, self-link exclusion, safe summary removal, semantic note retention, and download failures leaving existing output intact.

```bash
uv run --with beautifulsoup4 --with html2text --with requests \
  python -m unittest discover -s tests -v
```

To repeat the source-coverage audit, keep the Runtime/Driver HTML caches generated by the scraper and supply the saved official PTX HTML:

```bash
uv run --with beautifulsoup4 python tests/verify_source_coverage.py \
  --ptx-html /path/to/ptx-index.html
```

The audit checks PTX anchors, internal Markdown/HTML links, code examples, images, and API declarations/examples against their corresponding sources. Source inventories complement the conversion regression tests; these checks do not execute PTX or CUDA code.
