####  9.7.21.1. Miscellaneous Instructions: `brkpt`

`brkpt`

Breakpoint.

Syntax

```ptx
brkpt;
```

Description

Suspends execution.

PTX ISA Notes

Introduced in PTX ISA version 1.0.

Target ISA Notes

`brkpt` requires `sm_11` or higher.

Examples

```ptx
    brkpt;
@p  brkpt;
```
