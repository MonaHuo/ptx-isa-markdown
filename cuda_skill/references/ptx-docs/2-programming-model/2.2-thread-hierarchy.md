##  2.2. Thread Hierarchy

The batch of threads that executes a kernel is organized as a grid. A grid consists of either cooperative thread arrays or clusters of cooperative thread arrays as described in this section and illustrated in [Figure 1](2.2.3-grid-of-clusters.md#grid-of-clusters-grid-with-ctas) and [Figure 2](2.2.3-grid-of-clusters.md#grid-of-clusters-grid-with-clusters). _Cooperative thread arrays (CTAs)_ implement CUDA thread blocks and clusters implement CUDA thread block clusters.
